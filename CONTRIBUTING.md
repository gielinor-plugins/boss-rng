# Contributing

## Feedback

Bug reports, wrong drop rates, questions and ideas are all welcome by email at
gielinorplugins@gmail.com. For a bug, say which boss, what you expected and what
you saw. A screenshot of the details window helps.

## Code contributions

I'm not accepting code contributions yet, so please don't open pull requests for
now. If that changes, this file will say so, and contributions will be accepted under
the project's [MIT license](LICENSE).

You're welcome to read the code and learn from it. The
[technical docs](docs/README.md#technical) explain how it works, and
[docs/development/setup.md](docs/development/setup.md) covers running it in the
beta client.
