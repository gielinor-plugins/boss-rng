# Boss RNG

A RuneScape plugin that shows how lucky you've been with boss uniques. For each
boss and each unique, it compares the drops you got with what an average player
would have after the same kills, and shows how unusual your current dry streak is.

Boss RNG only reads what the game already shows you, keeps its data on your
computer, and never acts in the game for you.

## Install

Find **Boss RNG** in the Plugin Hub in game, or on its
[mod.io page](https://mod.io/g/runescape). Then open it from the Plugins window's
ribbon.
